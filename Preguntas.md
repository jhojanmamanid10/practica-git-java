1. ¿Qué función cumple main?
    Es el punto de inicio del programa Java.
   
3. ¿Diferencia entre javac y java?
* javac: compila el código .java.
* java: ejecuta el programa compilado.

3. ¿Qué archivo se genera después de compilar?
    Un archivo .class, que contiene bytecode.
   
5. ¿Por qué se llama Main.java?
    Porque si la clase es public class Main, el archivo debe llamarse Main.java.
   
7. ¿Qué pasa si la clase se llama Programa y el archivo Main.java?
* Si es public class Programa → da error.
* Si es class Programa → compila y genera Programa.class.
